# MSA-GoFuture

Итоговый проект спринта 6 курса "Микросервисная архитектура".

GoFuture переходит от Django-монолита к доменным сервисам с HTTP API на Python/FastAPI. Цели: более 500 000 конкурентных поездок, независимые релизы, горизонтальное масштабирование и поддержка новых регионов.

## Задание 1. Проектируем домены

Подготовлен годовой план постепенной декомпозиции с сохранением клиентских контрактов. Выделены девять доменных сервисов для восьми продуктовых команд. Payments отвечает за платежи пассажиров и корпоративные счета, Payouts за начисления и выплаты водителям. Оба сервиса принадлежат команде Payments, но имеют собственные БД, релизы и масштабирование.
