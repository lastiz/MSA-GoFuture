# ADR-005. Безопасность и комплаенс

## Контекст и требования

Глобальный публичный API требует защиты от атак, а персональные и финансовые данные - контроля доступа и размещения. Новые защитные механизмы и связи на [C2](C2-security.puml) выделены красным относительно заданий 1-2.

## Решение

| Механизм | Назначение |
| --- | --- |
| WAF и DDoS-защита перед региональными API | Фильтрация атак и ограничение аномального трафика на глобальном HTTPS-входе |
| VPC Firewall и закрытые подсети | Только разрешенные соединения. БД, Kafka и приложения не доступны напрямую из интернета |
| Kubernetes NetworkPolicy | Ограничение межсервисных соединений, включая доступ к БД только ее владельцу |
| IAM, TLS и проверка прав в сервисах | Аутентификация, разграничение операций и защита передачи данных. WAF не заменяет авторизацию |
| Хранилище секретов и управление ключами | Шифрование хранилищ и резервных копий, выдача секретов по минимальным полномочиям |
| Контролируемый исходящий доступ | Разрешенные платежные, банковские, картографические и push-интеграции |

На C2 защитные политики показаны на входе и границах сети. Сервисы, Kafka, IAM и адаптер старого API сохраняются.

### Стратегия комплаенса

| Область | Правило |
| --- | --- |
| Местные требования | До запуска проверить PDPA Сингапура, LGPD Бразилии и применимые нормы Индонезии и Чили |
| Размещение и резервирование | Определить разрешенные страны хранения, обработки и резервных копий. Передача в парный регион требует законного основания |
| Персональные данные | Хранить только необходимые данные, установить сроки хранения и порядок доступа и удаления с учетом финансовых обязательств |
| Платежи | Карточные данные остаются у провайдера, платформа хранит токены и ID. Требования PCI DSS оцениваются для выбранной интеграции |
| Логи и аудит | Не записывать секреты и точные координаты в технические логи. Фиксировать доступ и денежные операции, назначить ответственных за инциденты |

Если передача данных в парный регион запрещена, до запуска рынка нужен резерв в разрешенной стране. Наличие четырех площадок само по себе не доказывает соответствие законодательству.

## Альтернативы и компромиссы

WAF не заменяет сетевые ограничения и авторизацию. Многоуровневая защита сложнее в сопровождении, а правила требуют проверки на ложные блокировки. Комплаенс ограничивает выбор резервного региона.
